Projects

  • erebus - A Nix flake containing all of my system configuration. It features numerous custom packages, configurations for multiple systems, and secrets handling, just to name a few features. I've put a lot of effort into considering both form and function. Before this, I worked on another flake called nixfiles, which has gained more attention over the years.
  • cave 360 video converter - Written in Go as part of my software dev internship at MMU, this internal tool converts panoramic 360 videos into a format that can be used as a background for the university's cave facility.
  • Simple2FA - Written as part of my undergraduate studies, Simple2FA, as the name suggests, is a very basic two-factor authentication app. It has support for manual entry, as well as scanning QR codes, to import TOTP keys.
  • Graphics design work - While I haven't updated my portfolio in a while, I've done quite a lot of work in the graphics design space, creating logos and whatnot. I intend to move this portfolio to this website sometime in the future, but for now all my work happily lives on Behance.
